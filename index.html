Under the plastic: a bigram Markov chain. It counts which word tends to follow which, then rolls dice. No attention. No embeddings. No idea what it's saying. It is a language model the way a paper airplane is an aircraft — technically, yes.

Thinking mode is a trigram. That is the whole upgrade: it remembers one more word. Everything it shows you while deliberating is real — the actual candidate table, the actual dice roll, the actual elapsed time. Nothing is staged, which is exactly why it isn't impressive.

The gap: hit a word-pair it never saw and it hard-stops — perplexity ∞. A model like Claude never dead-ends there, not from seeing more, but because it computes a guess from a map of meaning instead of looking one up. The ∞ is exactly where lookup ends and generalization would begin.
